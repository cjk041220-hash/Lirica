## 三、支撑证据（全部实测，非转述）

### 加分项（核实过的）

1. **测试基线**：`c12869f` 后 882 项单测全绿；我上轮报告的 3 个问题（反馈中枢接线/性能毛刺/包名注释）全部修复并各补了契约测试（`ActionFeedbackHubTest` +21、`SafetyPolicyEngineTest` +10）。
2. **真机测试基建已就位**（写了但没跑）：`app/src/androidTest/` 有 3 个文件共 **16 个用例**——`SecureKeyStoreInstrumentedTest`(7，覆盖 AndroidKeyStore 硬件路径)、`RoomMigrationInstrumentedTest`(3)、`BackgroundWorkInstrumentedTest`(6，WorkManager 真机入队)。正是 09-25 评估指出的三个最高危验证空白。
3. **启动健壮性**：`LiricaApplication.onCreate` 第一行即 `LiricaCrashHandler.install()`（崩溃守护+环形日志）；lateinit 装配有自检测试守护（任何声明未赋值即红灯）。
4. **DB 迁移链**：`app/schemas/` v1→v6 六个 schema 全部导出，`MIGRATION_4_5`/`MIGRATION_5_6` 均有注册与测试。
5. **安全设计**：release 包 API Key 恒空（build.gradle.kts:52），BYOK 走 AES-GCM 加密落盘；降级密钥设备绑定随机生成（2026-10-02 P0 修复）；Manifest 无多余权限（CAMERA 明确不申请）。
6. **Onboarding**：两步引导（权限配置→Key 配置，OnboardingScreen.kt:66）完整存在。

### 减分项（核实过的）

1. **真机仪器测试 0 次执行**：`app/build/outputs/androidTest-results/` 不存在——16 个用例写完至今没连过一次真机。
2. **release 包从未构建验证**：`release` 块已开 R8 + shrinkResources（build.gradle.kts:44-45），但注释自认"真机冒烟待验收：无障碍/悬浮窗/Room/SSE"；且**没有配置 signingConfig**——`assembleRelease` 只能产出未签名包。
3. **APK 179M 未做架构拆分**：onnxruntime ×4 架构（19-32M 每个 ≈105M）+ ML Kit OCR ×4（≈46M）全量打包，未配 `splits`/`abiFilters`。你的真机只用到 arm64 那份，白背 100M+。
4. **文档滞后**：`docs/PROGRESS_TRACKER.md` 最新记录停在 Round 4（10-02），M5.1~M5.3 两轮落地（8dc910f/c12869f）未入 tracker——按你自己定的口径，"文档宣称 vs 代码现实"偏差又出现了。
5. **M5.4 未开工**：宏生命周期管理、内存基线、VLM 视觉接地仍在方案里，行动引擎的"好用地步"上限还没到。

## 四、如果现在要装：最小真机验证清单（建议 1-2 小时走完）

装 **debug 包**（别先碰 release——R8 混淆行为未验）。按序验证，任何一步挂掉就停在那是正常 alpha 体验：

1. 安装启动 → Onboarding 权限页各跳转是否可达（无障碍/通知监听/悬浮窗/使用统计）
2. Onboarding 配 Key（DeepSeek 或任意 OpenAI 兼容端点）→ 发第一条消息 → 流式回复正常
3. **杀进程重开** → 对话历史还在、Key 不用重配（验 KeyStore 硬件路径 + Room）
4. 悬浮窗拉起 → 快捷消息走通一轮工具调用
5. 通知监听：来一条微信 → 无障碍/通知事件是否进感知（看日志 tag）
6. 息屏等待 → 是否有 L3 通知送达（国产 ROM 大概率第一条就翻，翻了好，记下来）
7. 设置里切漫游模式 → 对它说"给 XX 发消息"→ 应被拦截并征询（验安全收口）
8. 让它执行一个简单 GUI 任务（如"打开设置"）→ 验 M5 链路首通
9. `adb shell dumpsys batterystats` 看一小时耗电占比
10. 跑一次 `./gradlew connectedDebugAndroidTest`（连着真机）→ 16 个仪器用例转绿，三个最高危空白同时清零

## 六、结论

**Lirica 已经是一台"装配完毕、出厂检验全在台架上做过、但从未上路跑过"的车。** 引擎（882 单测）、传动（接线自检）、安全装置（闸门/双态/隐私熔断）都齐了，质量在同类项目里是优秀的；差的是那一段**只有真机能给的验证**——而伴生类应用恰恰是所有品类里最吃真机实况的（ROM 杀后台、悬浮窗管制、息屏送达、硬件密钥）。

所以答案是：**可以打包、可以装、可以开始用了——以 alpha 的心态用。** 聊天和记忆大概率给你惊喜；主动关怀和行动引擎大概率第一周就会暴露一批只有真机才有的问题，那不是失败，那是 M4.0 欠的债终于开始还了。
