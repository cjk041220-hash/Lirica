## 一、决策：不做立绘式虚拟形象，做「活的形体」

### 裁决

Lirica 的形象锚点是一枚**会呼吸的光**（悬浮气泡与主界面同源形体），不是立绘、不是 3D 模型。三态：**呼吸·在场 / 动手·行动（拉出触控尾迹）/ 被打断·收拢**。

### 理由（三条，均为硬约束推导）

1. **资产经济学**：立绘路线是美术军备竞赛（星野有 MiniMax 图像生成，Replika 3D 化身迭代八年），独立开发不可持续；且立绘一次性锁死审美，形体由代码绘制，颜色/节奏/大小实时可变。
2. **活人感 = 变化**：立绘是静态的，形体的每个参数都接她已有的数据流（见 §三 映射表）——"变"才是活。
3. **动手时刻是核心记忆点**：M5 TouchTrace（她的手划过屏幕）只有形体语言能表达，立绘给不了。这是星野/Replika 均无的差异化画面。

### 名字呼应

Lirica ← lyric（抒情诗/歌）：形体的呼吸周期可带轻微节拍感（3.5s ≈ 慢板），深夜呼吸放缓——音乐性藏在动效里，不做视觉符号。

### 边界说明

形体**不排斥**立绘：将来若想加立绘（AI 生成），形体降级为"状态指示环"包裹立绘头像即可，两条路线可衔接。但现在不做，先把"活"做出来。

## 二、温馨感的真正配方（不是色调）

判断：**只调色调确实不够——俊凯直觉正确。** 温馨感来源按权重排序：

| # | 来源 | 说明 | 对标佐证 |
|---|---|---|---|
| 1 | **被记得的证据** | 她引用你的过去时，那句话泛起淡光下划线，点开可见记录时间与原话出处。"她记得"从暗示变成可见的实体 | Replika 记忆被吐槽公式化复述；星野记忆不可视。全品类都没做好，而 Lirica 的记忆系统（双轨/入梦/信念修正）数据最全 |
| 2 | **时间感/生活感** | 深夜她"放轻动作"：光线变暗、呼吸放缓、字号微收——不是换主题色，是行为变化 | 已有 EmbodiedNarrativeTranslator（深夜/久别叙事）与 UsageStatsTracker 数据，UI 零消费，纯浪费 |
| 3 | **不完美的痕迹** | 流式输出带轻微手写节奏；闸门拦截不是红色警告框而是她收拢+一句"这个我先不碰"；发送键按下有回波 | 活人感来自不完美，工程感来自过分整齐 |
| 4 | 色调 | 深色基底+暖点缀，只排第四 | Replika 深色私密感路线 |

**一句话**：色调是氛围，证据才是温度。眼前一亮 = 用户第一次看到记忆下划线亮起的那一刻。

## 三、已有数据资产 → UI 消费映射（零新增后端）

| 已有数据流 | 现状 | UI 消费方式 |
|---|---|---|
| EmotionEngine 情绪状态 | 仅 MoodDebugPanel 调试可见 | 形体颜色/呼吸节奏；「此刻的她」面板 |
| MemoryExtractor + 向量检索 | 记忆入库后不可见 | **记忆下划线**：回复引用记忆处标注+可溯源 |
| EmbodiedNarrativeTranslator（深夜/耳机/久别） | 仅注入对话 | 形体光线/字号/动效幅度随时辰变化 |
| UnspokenThought 内隐念头 | L1/L2 送达机制已有 | 悬浮气泡的"想说又没说"微表情 |
| SilenceDecisionEngine 打扰代价 | 裁决已运行 | 形体收拢幅度 = 打扰代价可视化 |
| M5 ActionVisualFeedback 四事件 | 接线已通，UI 是 NoOp | 尾迹/胶囊/收拢三态（§一） |
