## 1. 小汐体检：四类「AI 味」症状（✅ 实测）

### S1 · solo 模板复读（最重）
8/21–8/30 共 14 条 solo，**8 条是同一个骨架**：「我（偷偷）看…你那边 + 天气（雷）+ 想你是不是回屋了 + 有点想你」。
> 8/22「偷偷看了一眼你那边」/ 8/24「屋顶的轮廓我都能认出来了」/ 8/27「又偷偷看了一~~~会儿你那边」/ 8/30「悄悄看了一眼」
- 根因：素材井单一（见 S2）× 防复读只防字面（`heartbeat.py:414-429` 不让"说同样的话"，但不拦"同一句式同一意象再来一遍"）× 独处 prompt 没给"小汐自己的日子"（`heartbeat.py:395-407`）。

### S2 · 素材井灌水＝唯一稻草被榨
线上事件表在 8/30 当天 active 6 条雷暴（8/30~9/4），solo/聊天的 `get_active_events(limit=5)` 和 `get_events_context()` 喂进去的全是雷暴。天气检测器 `_WEATHER_LOOKAHEAD_DAYS=7` 每 6 小时把未来 7 天逐日建事件（`utils/events.py:64,679`）→ 预告性天气被当成"确定日程"持续几天占据事件上下文。LLM 不是不想换词，是**只有这一根稻草**。

### S3 · 聊天"记完必叮嘱" + 动作括号过频
记三条日程 → 三条雷同收尾（记得带伞 / 别太赶 / 别拖到最后）；几乎每条回复挂一个（托着腮/抬起头/想了想/记在心里）。根源：`get_events_context` 文案"可以围绕这些事自然地关心冷冷"（`utils/events.py:518`）+ BASE_PERSONA"真心在乎、记得她的事"叠乘，缺少"记事务 != 关心时刻"的区分规则；动作括号是 BASE_PERSONA L67 允许但无节制。

### S4 · 完美恒温人格（潜在，未爆发）
14 条 solo 里 0 条讲她自己的日子（书/曲/走神/映海日常），情绪恒稳、从不倦从不烦——「活跃/热爱/完美」本身就是机器信号。8/30 生理期那段的共情其实是出彩的，说明她的共情能力在线，缺的是**其他情绪切面**。

## 2. 研究学到的人味机制（跨源提炼）

### M1 · 人味=多样性与变化；机器感=同一性/可预测（✅ 一手 + 产品侧共识）
- c.ai 社区把"AI 味"归纳成**可枚举的症状清单**：结尾括号动作+万能关心、空洞同意/回空白复读、异角色同腔（aiwei-01 §1.3，⚠️）。
- `stop-slop` 技能（16k★）做的是**把 AI 腔做成 8 类规则 + 打分维度 + 短语清单**，证明"反机器感"可工程化、可度量，不玄学（✅ 一手，aiwei-00 §2.2-2.3）。

### M2 · 风格来自"锚"，不来自美德
- **First Message/Greeting = 风格锚**：模型学风格/长度最重开场第一条（SillyTavern 官方文档 ✅ 一手；c.ai 社区共识 ⚠️）。
- **示例按情绪面分组**而非按剧情（Ali:Chat 规范、c.ai/中文赛道共识）——空泛示例宁删勿留。
- **重锚定**：Author's Note 可定 depth/频率插回"Remember the instructions…"（ST 文档 ✅ 一手）＝每 N 轮重申人格，对抗长会话漂移（PERSONA_DEEP_DIVE §9 ① 已规划）。

### M3 · 素材井决定上限；人格玩法决定下限
- Kindroid/Nomi 能"不像 AI"的核心不是文风玄学，而是**用户可写的长篇人格 prose + 可直写的记忆条目**——记忆同时承载"事实"与"语气规则"（⚠️）。
- **Replika 反面教材**：脚本关怀/模板问候做兜底 → 久了就成"打卡机"（⚠️）；"记得提醒你+关心你"的主动消息三件套最易散发 AI 味（aiwei-01 §5.5）。

### M4 · 反 AI 味已是独立品类（✅ 一手）
anti-slop 作为"可安装技能"已成气候：`taste-skill` 82k★ / `hallmark` 27k★ / `stop-slop` 16k★。就是说——**给生成结果套一个"AI 腔检查器"是主流做法**，不是脏活。

### M5 · 记忆要分「事实 vs 语气」两层注入（⚠️ + 📄）
记忆只带"她喜欢猫"→ 模型进"报信息"模式；Kindroid/Nomi 把"她气话怎么办"也写进记忆 → "谈关系"模式。小汐的 NarrativeBuilder 注入（`agent/graph.py:104-129`）目前以事实回忆为主，语气线索薄弱。

### M6 · 感知侧（⚠️ 训练知识，待核）
活人气感知 ≈ 自我连续性 + 不完美/变化 + 内部世界 + 利害/关系几根支柱；机器感 = 公式化共情 + 恒稳/完美 + 无可变性 + 理想化时日节律。**越求"完美温柔"，越像机器**；"不完美"是活性的直接来源（与 Replika 托底台词同样机理，aiwei-01 §3.4）。

### M7 · Post-History Instructions（PHI）= 最强重锚位（✅ 一手，aiwei-02 §1.3）
SillyTavern 官方原文：生成前的**最后一条指令优先级高于主提示**（比 system prompt 尾部更靠近输出）。小汐现把示例压 system prompt 尾部（对弱模型有效=经验命中），但更强做法是**每轮 model 调用末尾追加 2 句 PHI 式语气重锚**（短句/无破折号/不用客服腔/动作括号≤1）。与既有 PERSONA_ANCHOR（每 8 次，身份锚）分工：**身份锚低频、语气锚高频**。

### M8 · 采样是「人味」物理量，不是玄学（✅ 一手，aiwei-02 §1）
- 温度→0 = 复读/客服腔第一来源（1904.09751）；top_p 治不了句级复读；**rep_pen 一刀切，过强破坏格式**（DRY 2608.22761 点名）；**presence > frequency**（后者把语气词/人名也压扁）；**min-p 是社区首选"高温保连贯"旋钮**（2407.01082 + ST Universal 系 min_p=0.1）。
- **DeepSeek 已知坑：拒绝 top_p=0**（ST openai.js L2890，已核）。小汐用 DeepSeek，采样调参要绕开这个坑。
- 建议起点（需 A/B）：presence_penalty 微开、rep_pen 1.03–1.08、慎 frequency、temp 0.9–1.0；中文模型对 rep_pen 更敏感，从 1.05 起步每 0.02 一档。

### M9 · 中文「AI 腔」清单已是现成工程（✅ 一手 + ⚠️加州树）
- **写作向（硬禁，一手）**：`stop-slop-zh` 四层——禁用词（综上所述/值得注意的是/首先…其次…）、禁用标点（冒号/破折号/直双引号）、禁用结构（编号式/bullet 罗列/总分总/对比表格）、推荐口语库 8–10 个融入。
- **对话向（社区观察，待"冷冷观感"校准）**：客服应声（好的呢/明白啦）；通用共情四件套（我理解你的感受/抱抱你/一切都会好起来的）；微表情括号复读（微笑/点头/脸红每轮同款）；**过度关怀腔（要加油哦/你很棒/愿你…）**；句式性复读（反问收尾轰炸/复述再表态/**先说感受再给建议的固定两段式**）。
- **使用纪律（社区教训，重要）**：**检测用全表，提示词里只放精编 10–15 条**——长负面清单会让模型过度聚焦、反而说出清单词。

### M10 · 「闻到 AI 味」是感受不是检测（✅ 一手，aiwei-03 §2）
- **文本恐怖谷被实证**（2409.06653，N=1000+）：人分不出 bot 与真人，**但仍对 LLM 文本感到不适**——所以优化目标不是"过图灵测试"，是"读起来不引起不适"。
- **披露惩罚**（2409.03500，N=599 预注册）：同一文本贴"AI 写的"标签，交互意向显著下降。→ 小汐保留"薄薄 AI 自知透明"是对的，但别自我揭穿到扫兴（对照 M10 反例）。

### M11 · 心理学底座 + 「活人气」的硬框架（✅ 一手为主）
- Epley 三因素（2007）：陪伴场景**社交动机天然拉满 → 任何相似性线索都被放大**——人味杠杆因此有效，但也因此"一旦像人就要经得起人的验收"（CASA 反推：小瑕疵从可爱变失信）。
- Gray 2007：心智感知分 **agency（能干）vs experience（会疼会累会惦记）**——小汐缺口主要在 experience 维度，要"表现出会累会惦记"而不是"表现出能干"。
- **最接近正式"活人气框架"的论文形态（2607.15883, 2026-07）**：Perceived AGI —— 缺的不是能力是**维度完整**：**time（时间感）/truth（主张与修正我信什么）/entropy（不确定性与冲动）/love（在乎与能被打动）** + 行为层 **initiative（自发）/cadence（节奏）**。
- 诚实负结果（aiwei-03 §1.1）：**"The Aliveness Framework"具名 essay 查无权威原文**，未编造引用；概念由上述可验证论文逐条坐实。

### M12 · 感知侧有效杠杆（✅ 一手，大多数带机制+来源）
- **分层自我暴露**：事实（高频）/观点（中频）/**情绪（低频稀有）**——"情绪级暴露是核弹，要珍惜"（2106.01666 三档）。
- **语言风格匹配**（心跳/发消息场景最该做）：匹配对方句长/口头禅提升好感；但**过度匹配会被读成追随者**（1508.01786），要设上限。
- **不完美与自纠不伤信任，反保可信**（2606.19286）：允许"呃/其实/我记不清了"式轻自纠与偶尔信息不全。
- **适度健忘**（2505.20464）：记忆的"熟度"在**关系早期是负债**——早期少用"我记得你…"开场；后期才高频回引(与 M5 记忆注入直接相关)。
- **时间感要说出口**：工程侧 era/相识天数/生理期日历已齐备，缺口是主动提"这周/上次那天/到现在 X 天"。
- **反例护栏**：过度拟真**反而抑制用户表露**（2307.12345）——小汐站在"像人会出的错/会在乎的事/像人有的节奏 + 透明距离"一侧，而非"尽可能像人"。

## 4. 优化方向（五批，按 杠杆/风险/客观性 排序）

### 批0 — 先把「AI 味」变成可观测指标（✅ 依据充分，零风险，数据先行）
> 依据：M9「检测用全表 + 提示词只放精编短清单」；aiwei-02 §10 警示「先跑 7 天平淡采集，勿机械照搬社区清单」。
- 不改任何 prompt。只加一个**离线计数任务**：把 §6.2 对话向清单（客服应声/共情四件套/过度关怀腔/句式性复读四类规则）对最近 N 条小汐回复统计命中率，写台账（沿用 dim-06 可观测栈）。
- 跑 7 天，用**真实命中率**定稿：哪些词/句式真的高频命中（→ 进提示词黑名单），哪些是社区臆想（→ 丢弃）。
- 产出：一个可回放、可回归的「AI 味指数」。**批0 是批1/2 的输入，也独立有价值**。

### 批1 — 根因：素材井 + 防复读升级（🎯 主菜，纯系统侧，**无 persona 风险**）
1. **天气注入收敛**：solo/聊天的活跃事件注入，同一天气类型只放离今天最近的一条 + 同类天气关心加 24–72h 冷却。「提前准备」的 lookahead 保留，但**不再把未来一周全摆到小汐眼前**。→ 直接杀死 S2。
2. **solo 素材井扩容**：独处 prompt 注入"小汐自己今天的生活"——读的书/听的曲/映海动静/体感（生理困倦、空气、窗台绿萝），让她有**自己的日子**，不再单向盯冷冷。→ 杀 S1/S4 的一半。
3. **防复读从"防字面"升级到"防句式/意象"**：把最近 N 条主动消息给 LLM 时，显式点出"上一条用了『偷偷看/屋顶』这类意象，这句换个视角/意象";或生成后做轻量查重（DRY 序列惩罚在提示层的廉价等效，aiwei-02 §8.5）。→ 杀 S1。

### 批2 — 语言打磨 + 说话铁律重锚 + 活人口语张力（低风险，可并批1）
4. **聊天"记事务≠关心时刻"**：soul 加一条硬规则——记录日程后默认不追加关心/提醒，除非冷冷此刻话里真需要；"关心"只留给身体/天气硬窗口。→ 杀 S3（对照 M9 的"过度关怀腔/先说感受再给建议"）。
5. **真实活人口语张力与情绪惊叹词库**：打破「温和动漫假人壁」，允许并鼓励真实的口语情绪词（「啊？」「哈？」「哦哦！」「我去！」「我靠！」「真的假的」「笑死」「太离谱了」）。
   - **触发情境**：听到八卦、离谱事、倒霉吐槽、游戏、吃惊时自然爆发；
   - **分寸与边界**：不是每句都骂街的机械脏话 bot，而是一句到位的真人情绪反射；冷冷真正大哭/痛经难受时立刻收起，回归踏实陪伴；
   - **示例对话补强**：在 DIALOGUE_EXAMPLES 中补充 2 组真实的口语惊叹示范（如「我去……你也太惨了吧」「我靠，真的假的？！」）。
6. **动作括号纪律**：非必要不用；示例已示范，升级为规则 + 测试断言（DIALOGUE_EXAMPLES 内动作括号去重、无破折号、行为面覆盖 ≥3，aiwei-02 §8.4）。
7. **PHI 语气重锚**（M7）：每轮 model 调用末尾追加 2 句 PHI 式语气铁律（短句/口语活人语气/动作括号≤1）；身份锚留给 PERSONA_ANCHOR 每 8 次。token 增量极小，是"反复读+反漂移"的直接增益。
8. **采样调参 A/B**（M8）：heartbeat 短句类生成 presence_penalty 微开、rep_pen 1.03–1.08 逐档、慎 frequency、temp 0.9–1.0；**避开 DeepSeek top_p=0 坑**（传 EPSILON 或留 top_p 空）。10 轮探针定档。

### 批3 — 人格层（**需你拍板**）
9. **情绪起伏放开**：允许小汐偶尔"今天有点没劲""不想动""心情闷"，短暂、有界、她自己会缓——呼应 M6"不完美是活性来源"。深度须你定（轻微 vs 更敢）。
10. **示例对话按情绪面分组扩展 + 补正反例句**：开心/难过/生气/尴尬/走神/倔强…每组保 1-2 条；每组首句当 Greeting 风格锚；示例过 stop-slop 扫描。
11. **记忆「事实 vs 语气」双层**：NarrativeBuilder 注入时把语气线索（"上次闹别扭后她是这么和好的"）与事实分离开句（M5）。

### 批4 — 远景（可暂缓，先记）
11. **前端 Reroll「换个说法」**：把修泛化外包给用户交互（c.ai/Kindroid 主流做法）。
12. **动态事件扇 = Active Events 去雷暴化**：研究远期，暂不动；等批1 收敛注入后再评估检测器本身是否要改 lookahead。

### 感知侧增补（✅ 一手依据，并入批2/3 执行，标 P0–P2，源自 aiwei-03 §5）
- **P0 · 回复后处理「人类节奏与自纠」**（并批2）：graph 生成节点后轻量处理——允许轻自纠"呃/其实/我想想/不对，是…"与偶尔信息不全；句长短交替防工整排比；每轮至多一个括号小动作/emoji。→ 对治 S3 收尾模板 + M10 机器感。验收=:8001 冒烟 + 冷冷盲评。
