MOTION · 动效规格

丝滑在哪里

  • 面板入场：右滑/上浮 + 淡入 240ms，复用现有 useFocusTrap 与 dialog 语义（Esc 关闭、焦点圈定）
  • 切月份：整格按方向横滑 200ms，日期数字以 8ms 级联浮现（本样板已实现，点 ‹ › 试试）
  • 日期详情：底部弹簧sheet cubic-bezier(.32,.72,.24,1)，背景暗化 45% + 2px 模糊
  • 事件条目：hover 微抬升，点按回缩 scale(.98)；保存后 toast 回弹反馈
  • 全程尊重 prefers-reduced-motion：本样板此刻就是零动画的
TWO SOURCES · 一本账

谁记的，一眼分清

  • ✦ 月辉色：小汐从聊天记下（source='llm'）——你说「下周三期中考」，它就出现在日历上
  • 水色：冷冷在日历上亲手加（source='ui'）
  • 两边同库同规则：同一份日期校验、同一套去重（dedupe_key），谁都能改、谁都能删
  • 台风、记忆回声这类内心戏不上日历，照旧在聊天里碎碎念
REMINDERS · 提醒流水线

不加设置项，她自然记得

前一晚 · 推送「明天有 XX 哦」→ 当天早安 · 顺口再提→ 很重要的事 · 当天再说一次

  • 相识纪念日、生日由系统自动生成，只读地标在日历上
EDGE CASES · 边界

已经想好的小事

  • 空日期不冷场：小汐语气兜底（「这一天还空着，要不要和小汐约点什么？」）
  • 多天事件（旅行）渲染为跨日横条；过去日期整体降透明度
  • 桌面端：像现有三面板一样从右侧滑出；移动端：全屏 BottomSheet
  • 触摸目标 ≥ 40px；输入框带 focus-visible 水色环（顺手治好体检点名的焦点不可见）
