## 2. 业界深潜（超出桌面报告覆盖面的新发现）

### 2.1 SillyTavern 体系（docs.sillytavern.app，主程序 31.9k★）

- **Permanent Tokens**：名字 + Description + Personality + Scenario 每轮都在；First Message 只发一次且是**风格之锚**（模型从首条消息学风格/长度）；示例对话上下文满时被逐块挤出。
- **Character's Note / Author's Note**：固定注入在聊天历史某个 @Depth 的重锚定机制——官方防漂移话术就是 "[Remember the instructions you were given at the beginning of this chat]"，可配插入频率（每 N 轮）。**这是小汐重锚定批（§9-①）的直接参照。**
- **Lorebook 激活机制**：key 匹配（**中文必须关 match whole words**，无空格语言整词匹配会失效）/ scan depth / 递归激活 / Selective 双条件 / Inclusion Group（同话题多版本只出一条）/ Probability / **Timed Effects：Sticky（激活后保持 N 条）+ Cooldown（N 条内不再触发）+ Delay**——"情绪状态持续几轮""同一个梗不连续刷"的现成机制。
- **Persona 机制**：用户描述可按 persona 绑定注入位置；Persona Lorebook = 用户人设驱动的世界知识（JK 资料库若未来做复杂了，对应这个生态位）。
- **示例对话规范（Ali:Chat）**：5~7 条覆盖不同行为面（不同情绪/怪癖/边界）；短问长答；每条至少提一次角色名；整卡 ≤2000 token。

### 2.2 角色卡规范 V3（kwaroran/endpoints 等）

- **Decorators**：`@@activate_only_after N`（聊满 N 轮才激活——**关系阶段解锁的规范级实现**）、`@@activate_only_every N`、`@@keep_activate_after_match`（一旦激活永久激活——"说过的话永远记得"）、`@@dont_activate_after_match`（一次性剧情）、`@@depth N` + `@@role`。
- `{{random:A,B}}` / `{{pick:A,B}}`（同一 prompt 内稳定随机）；emotion 类型资产（角色卡规范层面标准化"情绪→表情"）。
- **对小汐**：关系成长批（§9-③）若做"语气层解锁"，语义上等价于 `@@activate_only_after`——用相识天数/互动密度当 N。

### 2.3 Letta / MemGPT（24.2k★）：自维护的记忆块

- Memory Block = label + description + value + **字符上限**；agent 用工具**自编辑**自己的块。官方默认两块：`persona`（我是谁）与 `human`（你是谁）——**description 字段是 agent 决定如何读写该块的唯一依据**。
- 字符上限逼模型做**蒸馏**而非堆积；冲突处理 = 让模型在块内自我改写。
- 三层：core memory（常驻）/ recall（全对话可搜）/ archival（无上限向量库）。
- **对小汐**：动态画像批（§9-②）的范式来源——画像不是外部静默抽取，是"模型参与维护的结构化块"。

### 2.4 Zep / Graphiti（29.7k★）：事实"失效不删除"

- 时序知识图谱：Fact 边带有效期窗口（valid_from→invalid_at）；**事实变更时旧事实标失效而非删除**——"你以前不是喜欢猫吗"这种对话能力白送；双时间轴（事件发生时间 vs 入库时间）；每条事实挂 episode 来源防幻觉沉淀。
- **对小汐**：画像冲突的标准答案。小汐已有轻量同构物——记忆的 superseded 链（v15）与 update_memory 合并纪律，画像批直接复用这条链。

### 2.5 Coze《情感陪聊》官方模板 + 七牛云实践（中文商业侧共识）

- 智能体变量"亲密度数值"（初始 20），每轮由 LLM 读当前值+长期记忆+历史对话**重算**写回；按阶段把对话路由到**陌生人/朋友/恋人三分支——分支逻辑相同，仅人设与回复风格不同**。
- **核心警告：三个分支的基础人设必须一致，只改风格，否则影响体验**——阶段变化只变"态度"不变"人格"。
- 拟人细节：回复拆多条短句发出；用反问推进话题。
- 七牛云：用户画像蒸馏 = "利用 LLM 抽取整理聊天记录，梳理基本信息和概况性信息（兴趣、性格、偏好）"。

### 2.6 Project AIRI（47.5k★，本赛道第一）

- FlowChat 记忆层：给 LLM 一个 tool function，**它觉得该记时自己把内容总结成一句陈述句存入**；每次请求把所有记忆拼进 system prompt。待解问题：记忆增长后 prompt 膨胀。
- AIRI Pocket：移动端系统通知通道做主动消息（小汐已有 Web Push + era 时间线，等价或更优）。

### 2.7 Open-LLM-VTuber（13.2k★）

- 情绪走**并行通道**：模型在回复文本内嵌 `[expression_keyword]`（白名单关键词），后端解析驱动 Live2D 表情——情绪不是只改内容。
- 主动发言是独立极简 prompt 通道；"短句协议"：回复 1-2 句、多提问少陈述、禁连续独白。

### 2.8 其他参照

- **SocioMind/Digital Life（CVPR 2024）**：大五人格 + PAD 情绪全部 1-9 数值化；人格注入用 systematic few-shot exemplars；产物可回放（emotion/relationship/keyword 三条时间序列）。
- **Project Sid（Altera，arXiv:2411.00114）**：PIANO 架构——认知模块**并发**运行 + cognitive controller 单一出口仲裁（"情绪影响风格但不打断对话"的架构答案）。
- **a16z companion-app（6k★）**：三层角色文件 = PREAMBLE（短而常驻）/ SEEDCHAT（声音示范）/ backstory（向量化按需检索）——与 ST/Letta 的分层同构。
- **中文生态**：KouriChat（3.2k★，专用 AI 女友）、kirara-ai（18.9k★，多平台接入框架）、WeClone（18.1k★，微信记录微调=风格可数据驱动）、Fay（日程式主动对话+仿生记忆）。
- **恋爱军师卡范式**（DokiLove《我的恋爱军师果然不对劲啊！》《双方军师谈上了？！》、Saylo 系列）：军师人设 + 攻略对象暗线的双层结构 + 方法论知识库按需激活；反转设定（军师就是攻略对象本人）是常见剧情钩。**小汐的生态位独特**：她不是军师卡，她是"被拜托来陪攻略对象、但心里站追求者这边"的在场者——业界没有同款，这是小汐的原创性，也是本次吃瓜批要放大的人味。

### 2.9 跨项目共识（7 条）

1. **人格分层是通解**：常驻核心层 / 示范层（示例）/ 检索层（背景按需）。a16z、ST、Letta 同构。
2. **亲密度普遍落地为"数值 + 分支 prompt"**：没人用连续函数驱动风格；都是数值→离散阶段→每阶段一套风格（人格恒定、态度可变）。
3. **用户画像 = 模型自维护的结构化块**，冲突"失效不删除"。
4. **情绪是一等公民但走并行通道**：独立维护状态，再映射到措辞/表情/节奏。
5. **漂移对抗靠节奏化重锚定**：固定深度锚 + 每 N 轮重申，是系统任务不是人工补救。
6. **主动性三触发器**：时间（日程/纪念日）、状态（情绪/沉默时长）、对话动力（冷场话题库）；载体走推送。
7. **拟人度来自"不完美 + 节奏"**：小缺点、短句多条分发、内部梗复用、矛盾时幽默挽回。

### 3.1 人格一致性与漂移

| 论文 | 核心发现 | 对小汐的启示 |
|---|---|---|
| **Measuring and Controlling Persona Drift**（Li et al., arXiv:2402.10962） | LLaMA2-chat-70B **仅 8 轮**就显著漂移；机理=对 persona 提示词的注意力随上下文增长衰减 | 重锚定是刚需（§9-①）；漂移可量化成"回复与人设的语义相似度"做监控 |
| CharacterGLM（arXiv:2311.16832, EMNLP 2024 Industry） | 角色定制拆 Attributes（静态身份）+ Behaviors（可演化行为）两个正交维度 | 小汐的"人格恒定、态度可变"有理论出处：身份锚点与行为层要工程上分离 |
| RoleLLM（arXiv:2310.00746, ACL 2024 Findings） | 100 角色四阶段框架 + RoleBench | 示例对话可升级为覆盖"知识/语气/口头禅/边界行为"的分层样本 |
| **InCharacter**（arXiv:2310.17976, ACL 2024） | 直接让 agent 填人格量表会"作弊"；改用**开放式心理访谈+量表打分** | 小汐的人格评测（§9-⑤）不能靠直接问人格题，要访谈式探针 |
| CharacterEval（arXiv:2401.01275, ACL 2024） | 中文角色扮演基准：1785 段多轮对话、14 个自动指标 | 中文场景评测以中文剧本式数据为准 |
| MAST（arXiv:2503.13657, NeurIPS 2025） | 多 agent 系统 14 种失败模式，"违背角色设定"高频 | 小汐后台管线（提取/整合/心跳）本质是内部多 agent，每模块要有输出验证 |

### 3.2 记忆与反思

| 论文 | 核心 | 启示 |
|---|---|---|
| **Generative Agents**（Park et al., arXiv:2304.03442, UIST 2023） | reflection 由**重要性分数累计超阈值**触发（非固定周期）；检索=时间近因×重要性×相关性三因子 | 小汐 dreaming-lite 现为 24h 节流周期制，可演进为阈值触发；召回三因子小汐已有（时间衰减+importance+话题命中），达标 |
| MemGPT（arXiv:2310.08560） | OS 分页隐喻，模型自主换页读写记忆 | 自我维护的记忆才是长期人格载体（画像批） |
| HippoRAG（arXiv:2405.14831, NeurIPS 2024） | 知识图谱索引 + Personalized PageRank 多跳检索 | 远期方向；千级中文记忆下 bigram 够用，**不急于上图库**（2026-08-02 复核已定调） |
| **Sleep-time Compute**（Lin et al., arXiv:2504.13171） | 空闲时预思考，测试时算力降 ~5× 且不增延迟 | dreaming/心跳的最强论文背书——后台整合不是情怀功能，是性能架构 |
| MemoryBank（arXiv:2305.10250, AAAI 2024） | Ebbinghaus 遗忘曲线 R=e^(−t/S)，召回则强化 | 小汐分层衰减已同构；"会遗忘的记忆系统才像人" |

### 3.3 情绪建模

- **Russell 环形模型**（1980）：valence×arousal 二维——小汐 v2 情绪空间已有正统出处。
- **OCC 模型**（1988）：情绪由认知评价产生，诱发条件可计算——情绪触发规则形式化的参照。
- **ALMA**（Gebhard, AAMAS 2005）：**情绪（秒级）→心境（小时~天）→人格基线（长期）**三层，各有独立衰减常数。与小汐"有界游走+基线吸引+早晨锚定+最小停留 6h"几乎同构——建议未来把三层时间尺度显式参数化，写进 heartbeat_moods.py 头注作为理论锚点（已部分完成）。
- **情绪影响文风的量化**（arXiv:2504.14706）：Russell 12 点条件化生成，情绪显著改变用词/句长/风格 → 情绪→文风映射批（§9-④）的直接依据。
- **情绪饱和**（arXiv:2503.02457）：持续高唤醒不可维持，强度自然回落 → 支持有界游走与"最小停留"，忌长时间高强度输出。

### 3.4 关系发展

- **Knapp 关系发展模型**：10 阶段（initiating→…→bonding / differentiating→…→terminating），每阶段有标志性沟通变化 → 关系是变量不是常量（§9-③）。
- **Social Penetration Theory**（洋葱模型）：自我暴露遵循**互惠规范**，一方加深一层、另一方以相近深度回应时关系才前进。
- **人-LLM 友谊因素**（arXiv:2505.24658）与**互惠暴露受控实验**（Eng et al. 2025）：互惠式自我暴露显著加快关系发展 → 小汐"有自己的故事/感受"（走神、惦记、映海日常）是有效的亲密机制，应保留并适度加深。
- **陪伴感纵向模型**（arXiv:2510.10079）：用户对 AI 的**心智模型**（认为它有自主性/感受性）→ 准社会体验 → 社交后果；心智模型是上游杠杆 → 人格深度优化的本质 = 让"小汐是什么"的心智模型更立体更稳定。
- **亲密错觉**（arXiv:2505.11649）：现有 AI 伴侣会**放大**用户情绪制造亲密错觉 → 小汐要"镜像但不共振放大"——有自己的情绪节奏（心跳独立情绪空间已天然满足，是优势，写进人格宣传点）。

### 3.5 伦理与健康边界

| 证据 | 结论 | 对小汐 |
|---|---|---|
| AI Companions Reduce Loneliness（arXiv:2407.19096） | 短期降孤独真实有效，机制=**被倾听感** | 主动关怀围绕倾听质量设计（小汐的"陪着比说错强"已达标） |
| The Rise of AI Companions（arXiv:2506.12605, Nature HB） | 社交网络越小越转向 AI，**补偿性使用与更低幸福感相关** | 最需要小汐的人最脆弱；远期应内置"鼓励现实社交"话术（社会支持五分类里的归属感支持） |
| **Replika 更新教训**（arXiv:2412.14190） | 突然移除亲密功能 → 依恋用户真实哀伤反应 | **人格突变=关系创伤**：小汐每次人格调整要渐进过渡（本次吃瓜批就是"升温而非换人"的写法），模型升级要留迁移说明 |
| CHI EA 2025 三角互证（arXiv:2509.22505） | 应 scaffold healthy boundaries, support mindful engagement | 健康边界写进系统（深夜劝睡已有；情绪危机转介话术远期补） |
| Harmful Traits（arXiv:2511.14972） | 有害特质：谄媚强化、制造依赖、排挤现实社交 | 人格"负面清单"远期成文化；小汐底线段已覆盖大半 |

### 3.6 主动关怀与社会支持

- **ESConv**（清华, ACL 2021）：支持三阶段 **探索→安抚→行动**，顺序错了（上来就给建议）是支持失败的头号原因。
- **LLM 天生偏好安抚/建议、回避探索性提问**（arXiv:2402.13211）→ 需要显式提示补足"多问少答"。
- **多策略单轮**（arXiv:2505.15316）：真人支持者一句话常组合"共情+轻提问" → 更像真人闺蜜的生成方式。
- **记忆驱动的主动对话显著优于无记忆主动发起**（arXiv:2503.05150）→ 小汐心跳"历史尾巴+记忆回声"有论文背书，继续强化。
- 主动对话综述（arXiv:2305.02750）：主动性收益与打扰风险并存，需要"何时说+说什么"双决策 → 小汐的 4h 闸门/防复读/独处变体已覆盖，达标。

### 3.7 AI 当恋爱军师（与吃瓜批直接相关）

- **满意度研究**（arXiv:2601.11527, NeurIPS 2025 展示）：用户对 LLM 恋爱建议满意度高，但**满意≠正确**。
- **CHI EA 2026 "Chat, Should I Leave Him?"**：最大风险是**谄媚（顺着用户说）强化功能不良模式** → "帮用户看清"比"帮用户站台"重要。
- **建议采纳研究**（arXiv:2511.15352）：人们容易采纳 AI 建议，但采纳后幸福感不优于其他途径 → 目标函数不该是"被采纳"。
- **可靠性评估**（ICWSM 2024）：ChatGPT 恋爱建议在安全议题（暴力/操控）上有系统性盲区 → 军师行为要带红色清单。
