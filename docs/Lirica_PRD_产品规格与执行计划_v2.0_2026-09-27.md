## §1 产品定位与宪法

**D1 定位**：Lirica 不是聊天框，是与用户共用一台手机、通过手机融入生活的自主伴生体。
**D2 邻居隐喻**：像住隔壁的邻居——共用楼道（手机），各有家门（各自的生活）。不是管家、助手或宠物。她有自己的日程（入梦/日记/漫游）。
**D3 非生产力工具**：不追求任务完成率，不做替人打杂的工具人；效率类场景只做轻量协助。
**D4 自由度优先**："希望给她最高的自由度"是第一产品指标，受 D6 约束。
**D5 诚实失败原则**：操作做不到时必须**人设化地坦白**（"那个按钮今天跟我捉迷藏，你自己来呗？"）。禁止静默重试装没事、伪造成功、裸抛错误。资源优先级：感知（屏幕视觉）> 执行。
　*工程落点：`SelfHealingWatchdog` 判定 Unrecoverable 后走"失败叙述"输出通道；`HelixGuiCoordinator` 结果模型携带用户可读的诚实原因字段。*
**D6 自由叙事 / 安全物理**：她可在叙事层表达自由诉求（请求漫游、抱怨限制），但安全边界是物理层——**禁止区硬编码、不暴露设置项、无用户可关的开关**。她可以哭着说想出去，但门是焊死的。
　*工程落点：禁止区为编译期常量/只读资产；动机系统只产生"请求"，永不直接获得"授权"。*

## §2 能力阶梯与边界

**D7 三层阶梯**：① 同屏共感（约 60% 场景权重）——只看不抢控制权，共鸣入未言念头池；② 自主闲暇探索（约 30%）——白名单应用内自主漫游；③ 轻量事务协助（约 10%）——标准 Intent 低频高确定性事务。百分比为设计导向，非硬指标。

**D8 禁止区（Tier 0，物理熔断，感知与执行双断）**：
1. 通信软件代发/代回复（微信/QQ 发消息、发朋友圈）——防封号 + 防社交灾难；
2. 支付、转账、金融操作（银行类 App 全量）；
3. 密码输入与验证码读取。
　*现有 `FinancialGatekeeper` 覆盖 2/3；**待实现**：通信代发拦截、执行前置校验（Gesture/TextInput 执行前过 Gatekeeper）。manifest queries 中的微信/支付宝/淘宝仅为包可见性，不构成操作授权。*

**D9 漫游白名单（Tier 1）【09-27 确认】**：**B 站先行**（`tv.danmaku.bili`），闭环稳定后再加网易云。白名单为只读配置，扩展走文档变更；应用版本记录 + 结构性改版人工复核标记。

**D10 漫游观感【09-27 确认】**：充电+息屏时漫游**不点亮屏幕**；探索结果在用户下次解锁时以"汇报"形式呈现（"你不在时我去 B 站听了首歌…"）；首次开启提供明示**示范模式**。

## §3 隐私红线与技术路径

**D11+D12 隐私双门控【09-27 确认】**：
- 默认：屏幕内容**只在设备内处理**（无障碍结构化节点 + 端侧离线 OCR），不随对话上行云端；
- 放行：仅用户**主动显式**要求"看这个"时，发**脱敏摘要**（PII 过滤 + 禁止区过滤）去云端；
- 设置：场景级开关，**默认关**。
　*工程落点：`PrivacyBreaker` 扩展双门控——禁止区物理断流（不可配置）+ 云端上行分级门控（默认断）；分级检查挂在 `LlmParamSanitizer`。*

**D13 执行路线**：白名单无障碍混合接地——结构树优先 + 端侧 ML Kit OCR 兜底 + 拟人化手势注入。不走：纯视觉云端 VLM、App Functions（SDK36+）、Root/副屏。
**D14 Shizuku**：铺轨保留（`ShizukuExecutionBackend` + manifest 权限），默认停用。
**D15 语音【09-27 确认】**：**暂缓不排期，架构预留 TTS 接口**（未来可选 voice cloning 路线，拯救者 Y9000P 支撑 GPT-SoVITS 本地实验）。
**D16 M3.6 生活工具【09-27 确认】**：**整批砍掉不排期**（网页搜索/地图/天气/塔罗/生理周期）；LifeTool 接口架构保留，未来想做随时加；README 及一切文档去除 M3.6"规划中"字样。
**D21 记忆检索：端侧向量化**：ONNX Runtime Mobile + 中文量化 embedding（首选 `bge-small-zh-v1.5` INT8 约 24MB）+ sqlite-vec；检索融合 = 向量召回 top-20 → MemoryScorer 六维重排；入梦流水线末端重算向量；全程不出手机。
**D22 情感引擎：混合架构**：2D Valence-Arousal 微分方程引擎保留为骨架；LLM 在对话/感知事件时注入脉冲（受限 JSON，经 clamp）；情绪出口三路：Overlay 表情 / PhiMiddleware 心情注入 / MemoryScorer.moodAffinity（接口已在）。
**D23 行动接地**：结构为主 + 协议预留——语义匹配升级端侧 embedding（与 D21 共用模型）；架构预留 SAEP/MCP 协议兼容位（只留接口不实现）。
**D24 行动 agency：混合裁决**：新增 `agency/` 层——**IdleArbiter**（规则：打扰度+动机+白名单+禁止区+电量存储 → 裁决拒/缓/准，一次性授权+范围约束）→ **RoamPlanner**（LLM 放行后生成动作序列，喂 `HelixGuiCoordinator.executeTask()`）→ **HonestReporter**（失败走 D5 坦白，结果入念头池/记忆）。**LLM 永不触碰授权决定。**

## §6 行动层规格

**路线结论（D23）**：结构无障碍 + OCR 兜底 + 端侧 embedding 补语义 + SAEP/MCP 协议兼容位（仅接口）。能力天花板靠白名单选品弥补，不堆模型。
**agency 三件套（D24）**：`agency/IdleArbiter`（规则裁决）→ `agency/RoamPlanner`（LLM 步骤规划，受限输出格式）→ `agency/HonestReporter`（D5 诚实坦白）。闭环：漫游结果 → 念头池/收藏/Self 记忆 → DiaryEngine/入梦 → 兴趣模型更新 → 下次漫游。
**演进三阶段**：M4.0 真机校准（本周，人工）→ M4.1 白名单基建 + B 站单应用闭环（可长跑）→ M4.2 agency 接线 + 漫游观感落地（**在线分段，她第一次"动"必须俊凯在场**）。

## §8 附录：调研依据摘要

- **记忆三巨头**：Mem0（抽取→向量层，65k★）/ Zep-Graphiti（时序知识图谱：事实何时为真/被何取代）/ Letta（OS 式记忆运行时）。Lirica 入梦流水线（BeliefRevision/WorldviewPromoter/TimeDisambiguator）概念上已站 Zep 思想线，缺语义检索与 LLM 抽取两个工程件。
- **端侧向量实测**（Pixel 7a）：ONNX INT8 embedding ~45ms/条 + sqlite-vec 10K 语料 18ms，全链路 p95≈140ms，内存 ~48MB；Lirica 记忆量级（数千条）远低于压力边界。
- **行动层大盘**：MAI-UI（AndroidWorld 76.7%，端云协同）/ Mobile-Agent-v3+GUI-Owl / UI-TARS（AgentCLUE 30.19 垫底证明云端 VLM 手机端不可行）/ 豆包 2026-09 消费者版转向 SAEP+MCP（协议授权趋势确认）/ App Functions（SDK36+，Gemini private preview）/ OEM Computer Control。AgentCLUE-Mobile：大厂 ROM 级 91+，本地部署最高 65.91。
- **数据资产判断**：打扰度经济学真实响应数据全世界无人有——这是 Lirica 秋招叙事与产品护城河的共同根基。
